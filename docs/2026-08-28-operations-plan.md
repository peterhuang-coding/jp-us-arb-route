## 3. 路线执行（按调研修正）

- **路线 a（JP→CN→闲鱼）先行**：药妆 15-25% / 中古 20-40% 利润，小红书+闲鱼获客零成本；
  定价 = 日元价×汇率 + 5-20% 代购费，必收定金。首批 14 条候选已改闲鱼口径（卖价按 eBay 锚，实测时校准）。
- **路线 b 修正形态**：中国货带出境卖 eBay 被否（美国 de minimis 取消 → 中国原产货按中国税率 54% 或 $100/件征；
  双向海关红线）。正确形态 = **日本原产/日本限定货 → 日本直发 eBay 美国**，物流用 CPASS（内置关税预付）。
  前置：eBay 大陆个人卖家被堵 → 需执照或 ITIN（与 M1 资质表一致），决策后再启动。
- **发货三阶段**：0-30 单/月 自己带自己日本发（国際エアパケット 1,500-2,500円/kg）
  → 30-100 单 哥们仓（每单 500-1,000円+书面SOP）或転送JAPAN（保管6个月免费）
  → 100+ 单 专业代发（せかロジ 月980円起，接受个人）。

## 4. 风险清单（运行时红线）

1. **海关口径**：中国 5000 元免税额仅限自用；转卖属货物，需申报缴税（低频小量可控，别超量）
2. **日本侧**：免税品转卖日本境内=走私（我们货离境回国卖，合规；别在日境内倒卖）
3. **闲鱼新规五红线**：年销 10 万 / 年 104 笔 / 同款 5 次 / 在售 30 件——副业规模内可控
4. **eBay MC011**：封号按 IP/设备/支付关联连坐——将来做 eBay 时独立环境+独立支付
5. **大正感冒药金A**（含二氢可待因）与 **Dyson 日版 100V**：灰市/变压器问题，上架前人工复核（已标 ⚠️）
