# 转售卖家工作流与成熟工具：证据笔记

研究日期/网页访问日期：2026-09-12（Asia/Shanghai）。范围：10,000 CNY 周转金，2026-10-02—10-07 东京旅行采购、带回中国；已有闲鱼/得物使用路径，海外卖家账号尚未开通。本文是公开资料研究，未登录卖家后台、调用付费 API、注册账号、联系卖家、采购或改动业务代码/数据库。

## 与 9 月 11 日研究的差异

此前已记录基本工作流、精准同款、全成本和数据权限问题，见 [9 月 11 日研究](2026-09-11-reseller-sourcing-and-diagnostics.md)。本轮不重做界面或开发计划，新增核实重点是：SellerAmp 的指标反例、StockX 当前费用/交期和开发者准入、SNKRDUNK 日本站现金退出限制，以及一个主动经营长尾库存的卖家案例。S1/S2/S4 属于对既有来源的复核，其余是本轮补充证据。


**建议把 AI 的首要任务放在“核实一个准确 SKU 在用户现有渠道的销售证据、保守净回款与预计回款时间”，然后寻找低于最高采购价的货源。** 这是一项基于下列官方功能与用户约束的推论，不是“所有或大多数专业卖家都这么做”的调查结论。

成熟工具确实支持广泛发现商品、扫描条码和查看其他卖家的货盘，因此不必僵化为只能先搜索销售端。关键区别是：**发现可以从任何一端开始，买入必须通过销售资格、准确同款、需求、全成本和回款条件核验。** 目前没有证据证明这次东京行存在已验证盈利标的；工具的功能、平台成功案例和某次漂亮价差均不能补上这个缺口。

## 10 个已阅读的一手来源

以下除 S10 外，页面正文未显示可核实的发布日期，日期统一记为“未标明；访问 2026-09-12”，不把搜索引擎抓取时间当发布时间。短原文仅用于定位，其余为中文转述；技术判断只引用官方文档。

### S1 — eBay Product research（原 Terapeak）

- URL：[Product research](https://www.ebay.com/help/selling/selling-tools/terapeak-research?id=4853)
- 日期：未标明；访问 2026-09-12。
- 原文锚点：`actual price that the item sold for`。
- 事实：提供过去 3 年成交数据，包含接受 Best Offer 后的实际成交价；成交率指标限所查成交距今不超过 90 天。可以用 MPN/UPC/EAN 等编号、品相、地点与时间筛选。Seller Hub 用户可用；Sourcing insights 另需 Basic Store 或以上的商业卖家订阅。
- 可得性/局限：此次只读说明，未验证用户账号实际权限；不能据此承诺自动 API。eBay 成交不等于闲鱼/得物需求，查询混入其他版本会降低可比性；该页不支持把 sell-through 直接解释为用户某件货的售出概率。

### S2 — SellerAmp SAS 功能说明

- URL：[SellerAmp SAS Features](https://selleramp.com/features/)
- 日期：未标明；访问 2026-09-12。
- 原文锚点：`Should I sell it? Does it sell? Is it profitable?`
- 事实：面向 Amazon 的 RA/OA 等选品，提供扫码、销售资格/风险提示、Max Cost、费用/利润/ROI、估算月销量与估算售出时间、历史图表。支持店铺反查和 Google Sheets 导出，目标成本和利润由用户设置。
- 可得性/局限：能借鉴筛选顺序；其 Amazon 指标和费用不能直接用于国内平台，也不能证明实际利润。本文未开通试用、未输入真实货号实测。

### S3 — SellerAmp 对平均数据和实时数据的解释

- URL：[Buy Box, Charts and Offers: Interpreting average and real-time data](https://support.selleramp.com/portal/en/kb/articles/interpreting-average-real-time-data-for-product)
- 日期：未标明；访问 2026-09-12。
- 原文锚点：`owning the Buy Box doesn't guarantee sales`。
- 事实：Buy Box 占有率衡量获得该位置的时间，可能一直有位置却没有销售；SAS 不能预知实际交易。Live offers 来自 Amazon 网站，Recent offers 表示近一小时更新的报价。
- 可得性/局限：这是工具官方承认的指标边界，足以否定“占有率就是销量”。估算值、当前报价、真实成交必须在证据中分开，更新时间也不能混用。

### S4 — Keepa 官方 API 文档

- URL：[Keepa API Overview](https://keepa.com/api-docs/)
- 日期：未标明；访问 2026-09-12。
- 原文锚点：`Token-based access`。
- 事实：提供 Amazon 商品/价格历史、报价、Deals、榜单、卖家和跟踪数据；Product Request 接受 ASIN 或商品编码，Product Finder 支持复杂筛选。需订阅 API 方案和密钥，按 token 计量。
- 可得性/局限：这是现成可编程的数据来源，不代表免费、无需权限或覆盖国内退出价。只核实文档，未购买或实调；不能把 Amazon 历史价格当成已锁定的国内净回款。

### S5 — StockX 如何出售

- URL：[How do I sell on StockX?](https://stockx.com/help/articles/How-do-I-sell-on-StockX)
- 日期：未标明；访问 2026-09-12。
- 原文锚点：`Match immediately with the highest existing buyer Offer`。
- 事实：Verified Marketplace 支持 Sell Now 匹配当前最高买方报价，或设置 Ask 等待匹配；确认出售后须在两个工作日内发货给 StockX 鉴定。页面另述的 Listings/Live 市场有不同准入范围，不能混为一个渠道。
- 可得性/局限：最高买价是有时效的潜在退出依据，Ask 是卖方报价。尚未完成用户开户、收款、发货和商品适用性核验，不能将 StockX 计为这次行程已经可用的保底销路。

### S6 — StockX 卖家费用

- URL：[What are StockX's fees for sellers?](https://stockx.com/help/articles/what-are-stockxs-fees-for-sellers)
- 日期：未标明；访问 2026-09-12。
- 原文锚点：`3% payment processing fee`。
- 事实：Verified Marketplace 支付处理费为 3%；Level 1 基础交易费为 9%，并有地区最低费用。其他市场的费率结构不同。
- 可得性/局限：不能只算买卖价差，也不能把 12% 当成跨境全成本；实际运费、税费、汇兑和订单适用优惠仍需按用户自己的售出预览核实。没有把未来 10 月费率锁定为当前值。

### S7 — StockX 官方 API 接入流程

- URL：[API Integration Guide](https://developer.stockx.com/portal/integration-guide)
- 日期：未标明；访问 2026-09-12。
- 原文锚点：`Complete the developer sign-up form and wait for approval`。
- 事实：官方流程要求先有 StockX 账号、申请并等待开发者批准，再取得 API key、创建应用和完成 OAuth 授权。
- 可得性/局限：存在官方 API 与用户现在能调用是两回事。本轮无账号/权限实测，不能把外网看到的接口示例当成现成可用数据接入；没有推断审批时长或保证批准。

### S8 — SNKRDUNK 日本站交易流程

- URL：[取引のガイドライン](https://help.snkrdunk-guide.com/ja/articles/%E5%8F%96%E5%BC%95%E3%81%AE%E3%82%AC%E3%82%A4%E3%83%89%E3%83%A9%E3%82%A4%E3%83%B3-82dac5b4)
- 日期：未标明；访问 2026-09-12。
- 原文锚点：`鑑定には1～4日程度`。
- 事实：出品后由买方购买付款，卖方须按期限寄件，再经过鉴定/检品。页面表示鉴定约 1—4 日；通过鉴定后卖家获记销售余额，还需申请提现。
- 可得性/局限：挂牌、成交、鉴定通过、余额、银行到账是不同状态。说明中的通常时长不是该次订单保证；不能把旅行时看到的可售价格当作旅行结束前现金已回笼。

### S9 — SNKRDUNK 日本站提现

- URL：[売上金・振込について](https://help.snkrdunk-guide.com/ja/articles/%E5%A3%B2%E4%B8%8A%E9%87%91%E6%8C%AF%E8%BE%BC%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6-ce38694d)
- 日期：未标明；访问 2026-09-12。
- 原文锚点：`日本国内の金融機関のみ`。
- 事实：账户销售余额为售价扣销售手续费和平台便捷寄件费用；提现再收手续费，且只支持日本国内金融机构，不支持海外银行汇款。到账安排还依申请时段和银行营业日而定。
- 可得性/局限：这是现金退出的实质条件。未验证用户持有合格日本银行账户，故日站只能列为待核验渠道；不能从此推断其他国家/地区版本也采用同样规则。

### S10 — 真实卖家案例：Lavender Clothes Line 的 Karen

- URL：[Finding Treasures and Creating Community on eBay](https://www.ebayinc.com/stories/news/finding-treasures-and-creating-community-on-ebay/)
- 日期：2020-10-02 发布；网页元数据最后修改 2020-10-29；访问 2026-09-12。
- 原文锚点：`inventory usually turns over in about 15 months`。
- 事实：官方采访记录其从旧货店、庭院甩卖、跳蚤市场等采购，日常包含拍照、上架、采购和发货。她自述选择长尾生意，持有数千件库存，全店通常约 15 个月周转。
- 可得性/局限：单一具名卖家的自述、平台选出的宣传案例，没有独立审计净利润，不能代表行业总体。它尤其能说明：能长期经营的模式，不必适合资金少且希望较快回款的新进入者。

## 本轮最有说服力的 5 点

1. **“卖得动”的指标不是确定买家。** S3 直接给出有 Buy Box 却无销售的反例；S1 的 sell-through 也不是对用户单件商品的成交承诺。此前的销售证据分层因此有了工具官方的具体反例。AI 的新增价值应是识别数据口径、样本和时效，避免把估算变成“已有买家”。
2. **销售端应先被验证为用户可用，海外价差只能暂作研究线索。** StockX 的 Sell Now 有明确买方报价匹配机制，但还要两工作日寄出（S5）；日本 SNKRDUNK 经过鉴定才记余额，提款仅支持日本境内金融机构（S8/S9）。用户海外账号未开通，不能把它们算作已成立的现金退路。
3. **净利计算要使用当前市场类型和用户订单条件。** 本轮核实 StockX Verified Level 1 的 9% 交易费加 3% 支付处理费（S6），仍不包含所有跨境成本。AI 可以汇总费用依据、提示缺项；不能把通用百分比或其他市场的优惠直接套到用户身上。
4. **专业卖家也可能选择长周转，经营模式要服从资金约束。** Karen 约 15 个月全店周转（S10）是一个反例：专业不必等于快周转。对本次 1 万元应先明确持货期限和回款需求，再决定买什么；不是看到别人经营成功就复制其库存结构。
5. **采用成熟数据源仍须验证实际权限。** Keepa API 需订阅和 key（S4），StockX 要先申请获批再 OAuth 授权（S7）。因此先用一个准确 SKU 证明国内销售端数据可得、费用可核验，再决定自动取数投入；不能把“有 API 文档”写成“已经接通”。

以上 AI 优先级和行程适用判断均是研究推论；功能事实来自所标来源。未做行业普查，没有据此宣称专业卖家的多数做法或盈利概率。

## 对当前路线的增量建议

| 方向 | 本轮证据带来的调整（推论） |
|---|---|
| 先选销路 → 精确 SKU → 找货 → 净利/周转 → 执行/库存 | 沿用已讨论流程；明确发现可从货源端开始，但采购前必须完成销售资格、需求、成本和回款核验。 |
| 广泛找买家/卖家 | S2 的店铺反查说明它是合理的候选发现方式；但看见他人在卖不能得出其净利和用户的确定买家，应在准确 SKU 上验证。 |
| 地图 | 对已经通过筛选的采购点有用；当前没有新增证据支持继续扩地图优先于补国内成交与净回款。 |
| 抢购/竞拍 bot | 可能提高确认机会的响应速度；本轮没有找到证明它能补足销路或收益的证据，暂不作为当前最重要工作。 |
| AI 日常助手 | 优先整理中日规格、成交证据类型、费用和最高采购价，之后帮助上架草稿和实收对账；计算应使用明确规则，不能由模型猜数。 |

**唯一下一步：** 选一个东京确能采购的准确货号/尺码，在现有国内销售渠道取得可复查成交和实际卖家费用，做一张最高采购价与回款期限卡片。它仍可能得出“不买”；这也是有价值的研究产物。
