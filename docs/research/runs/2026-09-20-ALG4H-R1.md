## 已验证的变化

- 财务计算拒绝非法数值、布尔值、溢出及显式未知费用；省略费用仍保留零默认，合法数值字符串兼容。未知费用不能制造利润。
- API 金额/数量字段不再接受布尔值；前端排除二月三十日等被 JavaScript 自动滚动到下月的日期，保留 72 小时有效期、闰日及带时区时间戳。
- 采购组合不再把价格四舍五入到整元。原反例：预算 2 元、单价 1.49 元却选择两件，花 2.98 元；现在正确选择一件。预算 3.02 元、单价 1.51 元现在可选两件。
- 组合算法采用精确稀疏动态规划，状态/计算工作量超限明确失败，不输出未经证明的近似采购单。目标仍是既有自用节省，不等于转售利润。
