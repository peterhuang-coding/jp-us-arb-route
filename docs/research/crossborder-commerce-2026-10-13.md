## 2. 平台可用性条件

- **Etsy**：E1 直接阅读——中国区"新店铺当前无法在华开设；此前已开设的店铺可使用 Etsy Payments"。**支付支持 ≠ 新店资格**，两者不可混为一谈。E2 官方检索结果：vintage 类目要求物品**至少 20 年**并可能要求年代证明；"收藏级""复古风"不满足条件。
- **Shopify**：E3 直接阅读——Shopify Payments 支持名单含中国香港、日本、新加坡、英国、美国，**不含中国大陆**；名单外地区需第三方支付商。这不等于 Shopify 店铺软件不能在大陆使用，但主体地址、审核与支付商可否签约均待核。
- **eBay**：E4/E5——费用按**注册国家/地区与销售额**区分，页面明确把美国卖家与其他地区卖家分开；**不得把美国 1.65% 国际费等套用到中国账户**。中国账户的注册资格、放款方式、类目限制、完整费率表全部待核。

## 4. 收款、物流、关税与成本公式（框架，非报价）

**路线A 到岸成本**：
`K_A = 采购价Q + 采购地税/境内运费 + 国际运费 + 保险 + 清关代理费 + 实际关税及进口税 + 国内尾程 + 适用鉴定/品相处理 + 平台费 + 收款/汇兑费 + 售后损耗 + 营销及适用仓储`
`利润 π_A = 可信目标市场销售收入P − K_A`
硬约束：E6 明确零售进口商品不得再售；商业进口通道书面核实前，此公式仅供研究，**不得据此进货**。

**路线B 履约成本**：
`K_B = 采购价Q + 国内集货费 + 国际物流/保险 + 适用出口手续成本 + 平台刊登/佣金 + 收款/汇兑费 + 卖家实际承担的目的国税费 + 经确认适用的产品合规成本 + 退货损耗 + 营销及适用仓储`
`利润 π_B = 可信目标市场销售收入P − K_B`
`全成本ROI = (P − K) / K；销售净利率 = (P − K) / P`。每项仅计一次，报价含税/含运或平台代扣须拆分；平台代收代缴且不归卖家的税不同时当收入和另计成本。区分已知费用与假设准备金；存在未核重要成本则K不完整。在取得可信P和完整K前利润与最高买价未知，短期合格转售仍须两口径均达50%；长期收藏不按假定未来涨价计算回报。

## 5. 30 天研究验证步骤

- **D1–5 资格与法规桌面核验**：核实际主体注册地（不预设）；查E1–E5公开官方资格、费率、放款及支付商签约条件；读取E6及商业进口、中古玩具准入、HS归类原文。需要咨询海关/报关行的事项留成问题单，由用户决定联络，不自动致电或付费。
- **D6–12 货源核验**：读取M1/M2/M3公开配送与交易条款；旧失败输入不反复发包，优先新来源；Mandarake查现行具体商品而非2010年旧文。国内端也补具体供给和真伪凭证。每个SKU记录准确版本、品相附件、收藏理由、低价竞争、对应目标市场成交、来源URL及观察时间。
- **D13–20 实费取证**：优先获取公开货运和收款费率及适用条件，有条件争取两组对照但不凑数；需主动询价的留待用户另授权。仅对拟销售目标地查产品安全和税费；欧盟GPSR不能替代英国或美国规则，官方材料仍不可读则保留未知。
- **D21–30 单 SKU 档案与 go/no-go**：选证据最完整的一个 SKU（结果可能仍为零），填满 P 与 K、合规清单、退货路径；达不到证据门槛即结论"暂缓"，不采购、不上架、不报盈利预期。

## 6. 验证顺序与尚未能作出的选择

主审未采用原稿“出口更适合”的经营结论：本轮没有国内准确玩具货源、任何目标市场成交，亦不能推断用户可实地验货或进口必然30天内做不成。不能从个人跨境零售不得再售推出所有进口转售不可行。两路均须继续比较。

建议优先做两个独立验证包：A选Joan Cornellà或AKIRA一件准确作品，补海外供给、大陆成交及商业履约条件；B选有真实国内供给的一件作品，先核eBay主体资格及该目标国成交与配送成本。eBay资格可作为先做的桌面检查项（推断），不是已证最优平台。独立站先核支付与获客成本，未有客群证据前不建站；Etsy大陆新店当前限制使其不宜作为该主体下的首发方案。

选路条件：相同作品/版本、可核真伪品相、目标市场有效成交、真实可执行渠道、完整K和退货路径均具备后，再比较资金占用、净收益及流动性；目前不能选出经营赢家。主体设立与试销均不在本次授权内。30天仅为建议的验证顺序，沿用每轮预算与停止条件，不额外触发任务或外部联络。
